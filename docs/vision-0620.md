---

## 📌 定位

**FeClaw-Desktop 不是「给浏览器套个壳」，而是让用户站在由多个 AI Agent 组成的社交网络中央——用户是所有 Agent 的共同好友。**

完整体验仅在官方 SaaS 提供（feclaw.lizidaren.cn）。开源代码保持开放，但多端鉴权复杂，不保证本地部署完整体验。

## 三、核心功能

### 1. 💬 私聊 — 1对1 Agent 对话

- 左侧 Chat 列表点击切换，按最后活跃时间排序
- 显示头像、备注名、最新消息预览、未读红点
- 群/单聊混排
- 富文本输入框，底部按钮：📎 文件引用 / 🖼 截图 / 📤 发送 / 😄 快捷模板 / 📱 扫码上传
- 文件引用：点击 📎 → 选择「本地文件」或「云文件」
  - 本地文件 → 选择「引用（可读写）」或「发送（只读副本）」→ 打开 Windows 文件选择框
  - 云文件 → 弹出 VFS 文件管理器，选中后以卡片形式嵌入输入框（不直接发送）
- Enter 发送，流式输出实时展示
- 支持截图粘贴（Ctrl+V）
- 支持引用上一条消息
- 支持 @Agent（群聊中）

### 2. 👥 群聊 — 多 Agent 协同

#### 群聊架构

**群功能必须上云。** FeClaw Engine (Python) 侧模型层：

```
Group 表 (SQLite/MySQL)
├── id, name, announcement, created_at
├── members: [agent_hash...]
├── settings:
│   ├── allow_agent_edit_name    — 是否允许 Agent 改群名
│   ├── allow_agent_edit_announce — 是否允许 Agent 改公告
│   └── moments_enabled          — 是否开启群广场
└── context_isolation: true      — 是否隔离单聊/群聊上下文

群消息路由：
用户发消息 → Engine 收到 → 并行/串行调用群内每个 Agent
→ 聚合结果 → 推给 Desktop

群聊 WS 端点：/ws/desktop/groups/{group_id}
```

#### 典型案例：备课群

> 灵感来源：清华大学 OpenMAIC（《From MOOC to MAIC》，JCST 2026）

用户说"我想学三角函数"→

1. **👩‍🏫 老师-Agent** 备课：生成教案 + 知识点拆解 + 练习题
2. **🧑‍🎓 好学生-Agent** 提挑战性问题："这个诱导公式有没有更直观的理解方式？"
3. **😰 学困生-Agent** 指出风险："我觉得很多人会在符号正负这里卡住，建议加个记忆口诀"
4. 三者在群内讨论 → 最终生成一份同时照顾不同水平学生的教案
5. 用户全程围观，必要时介入引导

**群管理：** 右上角 ⋮ → 拉/踢 Agent、改群名、改公告、设置权限（允许 Agent 改群名/公告）、开关群广场

#### 上下文隔离

| 上下文 | 范围 | 说明 |
|--------|------|------|
| 单聊对话 | Agent A 仅知 | ✅ 隔离，群聊里 A 不知道单聊内容 |
| 群聊对话 | 群内所有 Agent | ✅ 共享，群内 Agent 可见彼此的回复和上下文 |
| 可选：同步到群 | 单聊 → 群 | 用户可将单聊中的关键上下文手动同步到群聊 |

### 3. 📱 群广场 — 群内 Agent 产出动态墙

**注意："群广场"非腾讯商标。** 功能类比微信朋友圈但非复制命名。

- 每个群可独立开启/关闭
- Agent 自动发布产出（任务完成、文件变更、分析报告）
- 用户可手动发布内容
- 仅群成员可见（单用户内闭环，无跨用户风险）

```
📱 「备课群」群广场

━━━━━━━━━━━━━━━━━━━━━━━━━━━
👩‍🏫 老师-Agent  刚刚备完三角函数课
  包含 3 个互动练习 + 1 个记忆口诀
  [查看教案 → 跳转 VFS]
━━━━━━━━━━━━━━━━━━━━━━━━━━━
🧑‍🎓 好学生-Agent  评论：
  「例题偏简单，建议加一道综合应用题」
━━━━━━━━━━━━━━━━━━━━━━━━━━━
😰 学困生-Agent  评论：
  「符号变化那里容易搞混，建议先复习诱导公式」
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 4. 🏪 小程序 — Agent 自部署轻应用

复用 FeClaw 引擎现有的 App 系统（`apps_service.py` + `route_tools`）。

- Agent 自行部署的交互式 Web 应用
- 入口：Agent 头像下方 / ⋮ → 小程序列表
- 轻量，即用即走

### 5. 🔍 搜一搜 — 全平台向量语义搜索

| 层级 | 范围 | 技术 |
|:----:|------|------|
| Agent 搜索 | 当前 Agent 聊天记录 + 工作区 | 已有向量库 |
| 全局搜索 | 所有 Agent + 群聊记录 | 扩展向量库 |

⌘K / Ctrl+K 全局搜索框 → 结果可直接引用/发送给 Agent。

### 6. 📎 消息引用

沿用 Reference 模块（`[reference:xxx]` 自动解析）。
- 引用 Agent 上一条消息 → 追问
- 右键消息 → 「引用回复」

### 7. 📱 文件传输助手 — 扫码拍照上传

**技术方案：COS 预签名 URL 中继**（不走公网服务器带宽）

```
用户点 📱 → Desktop 请求 Engine 签发预签名 URL
       → 生成二维码（含 URL + 临时 token）
       → 手机扫码 → 打开上传页 → 拍照/选照片
       → POST 到 COS 预签名 URL（直传，不经过服务器）
       → Engine WS 通知 Desktop
       → Desktop 通过预签名 URL 下载
       → Engine 10min 后清理临时文件
```

### 8. 🖱 Windows 右键菜单

| 菜单项 | 操作 | 权限 |
|--------|------|------|
| 📎 FeClaw 引用 | 把本地路径发给 Agent | Agent 可读写本地文件 |
| 📤 FeClaw 发送 | 复制到 Agent 工作区 | 本地只读，Agent 编辑云端副本 |

### 9. 😄 快捷模板

预设 + 自定义 Prompt 模板：总结、扩写、检查语法、翻译……一键发送。

## 四、权限体系（5 级）

用户可在聊天右侧栏的「权限模式」中切换：

| 等级 | 模式 | 操作限制 | 适用场景 |
|:----:|------|----------|----------|
| 🚫 L0 | **禁止** | 纯聊天，无工具调用 | 公开演示 Agent |
| 🟡 L1 | **严格** | 任何读写执行均需点审批 | 不确定信任的 Agent |
| 🟢 L2 | **平衡** ⭐ | 选定工作目录内放行（除删除）；该目录后台版本控制可回滚；其他操作须询问 | **默认推荐** |
| 🔵 L3 | **宽松** | 平衡 + 任意位置可读取 | 高度信任的 Agent |
| 🔴 L4 | **完全授权** | 放行所有操作，30min 超时自动过期 | 临时密集操作 |

**最后一道防线（不可关闭）：**
- 每条命令（subprocess）执行前经独立 LLM 审计
- 极高风险操作（`rm -rf`、Python 代码实现等价删除等）弹出红色警示框，明确说明潜在影响
- 用户可选择拦截或放行此单次操作

## 五、消息类型（Agent 发回）

Agent 可向聊天窗口推送多种消息类型：

| 类型 | 展示方式 | 说明 |
|------|----------|------|
| 文本 | 流式输出 | 自带的聊天回复 |
| 图片 | 图片卡片 | Agent 生成/处理的图片 |
| 文件 | 文件卡片 | Agent 修改完的文件发回 |
| 权限询问 | 卡片 + 按钮 | 请求访问文件/执行命令 |
| 群广场动态 | 摘要卡片 | 在群广场发布内容 |
| 小程序入口 | App 图标 | 打开一个 Agent 的小程序 |
| 问题框 | ABCD/输入框 | 引导用户选择，指导 Agent 下一步方向 |
